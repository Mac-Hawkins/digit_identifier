# Welcome to Digit Identifier

This is a project I'm currently working on to gain more experience in Python, TensorFlow, numpy, and machine learning.

The project currently consists of a basic web [page](https://mac-hawkins.github.io/digit_identifier/) that will let users draw a number from 0-9. I then have Convolutional Neural Network (CNN) predict what number was drawn and display that prediction to the user.

## Dataset

The CNN was trained using TensorFlow and the [MNIST](https://en.wikipedia.org/wiki/MNIST_database) dataset. This dataset contains greyscale images of white numbers on a black background. These images are of size 28x28 pixels.
