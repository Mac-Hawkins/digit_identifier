# Welcome to Digit Identifier

This is a project I'm currently working on to gain more experience in Python, SQL, TensorFlow, pandas, numpy, and machine learning.

I plan on creating a basic webpage that will let users draw a number from 0-9. I will then have machine learning models predict what number was drawn and display the prediction to the user.

## Dataset

This project uses the [MNIST](https://en.wikipedia.org/wiki/MNIST_database) dataset to train and test the models.
